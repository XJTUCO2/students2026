# 团队成员网页 · GitHub Pages 展示版

此版本可直接使用 GitHub Pages 发布，无需 Node.js、服务器、银行卡或模型接口。包含 108 位成员的资料、照片、搜索筛选、地图和固定导航。点击“资料登记”可打开 WPS 表单。

## 发布

1. 创建 Public（公开）仓库，建议将此展示版单独放在新仓库。免费 GitHub 账号使用 Pages 需公开仓库，网页和照片均可公开访问。
2. 解压并上传此目录内的文件，index.html 必须直接位于仓库根目录；不要上传 ZIP 或额外套一层文件夹。照片多时使用三批上传包，每批解压后将内容合并上传到同一仓库根目录。
3. 仓库 Settings → Pages → Source 选择 Deploy from a branch；Branch 选择 main（或实际上传分支），目录选 /(root)，点击 Save。
4. 等待发布后，在同一页面点击 Visit site，分享生成的网址。电脑关机也能访问。

此版本没有账号、弹幕、留言墙和管理员后台。完整后台版仍保留在原项目目录，未被修改。
