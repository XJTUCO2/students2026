# 团队成员社区 · GitHub Pages 完整版

解压后将本目录内全部文件与文件夹上传到仓库根目录，index.html 应直接位于根目录。请勿上传 ZIP 本身。照片超过单次上传文件数时，可分批上传 photos 文件夹内文件，保持 photos 路径。

包含成员资料、照片、搜索、城市地图、带日期的寄语弹幕、CC 小助手和教师主页链接。小助手通过复制草稿并打开 WPS 表单收集需求，需在表单中提交。此版本不包含登录认证、共享访问排行榜或自动同步留言。

在仓库 Settings → Pages 中选择 Deploy from a branch，选择上传的分支和 /(root)，保存后等待发布。
